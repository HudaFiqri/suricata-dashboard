# Agent Installer Design

## Overview

Single self-contained `.sh` script that installs and configures the Suricata Agent on remote hosts.

**Key Features:**
- Single file download via `curl`
- Embedded Python agent code (base64 encoded)
- Embedded systemd service
- Auto-generated configuration
- Zero manual setup required

## Script Structure

### Template: `agent/installer/template.sh`

```bash
#!/bin/bash
#
# Suricata Dashboard Agent Installer
# Auto-generated by: https://dashboard.example.com
# Generated at: 2025-01-14T10:30:00Z
#
# Usage:
#   curl -sSL https://dashboard.example.com/agent/install.sh | sudo bash
#
# Or with custom name:
#   curl -sSL https://dashboard.example.com/agent/install.sh | sudo bash -s -- --name my-agent
#

set -e  # Exit on error

#==============================================================================
# CONFIGURATION (Injected by generator)
#==============================================================================

DASHBOARD_URL="https://dashboard.example.com"
AGENT_TOKEN="eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."  # Encrypted token
AGENT_ID=""  # Will be assigned during registration
SECRET_KEY_HASH="abc123..."  # For token encryption

# Optional pre-configured values
AGENT_NAME=""  # Empty = prompt user
AGENT_TAGS=""  # Comma-separated

# Paths
INSTALL_DIR="/opt/suricata-agent"
CONFIG_DIR="/etc/suricata-agent"
DATA_DIR="/var/lib/suricata-agent"
LOG_DIR="/var/log/suricata-agent"

#==============================================================================
# EMBEDDED AGENT CODE (Base64 encoded)
#==============================================================================

# Agent Python package (tar.gz, base64 encoded)
AGENT_PACKAGE_B64="H4sIAAAAAAAAA+1..."

#==============================================================================
# EMBEDDED SYSTEMD SERVICE
#==============================================================================

SYSTEMD_SERVICE='[Unit]
Description=Suricata Dashboard Agent
Documentation=https://dashboard.example.com/docs
After=network-online.target suricata.service
Wants=network-online.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/suricata-agent
ExecStart=/usr/bin/python3 /opt/suricata-agent/agent.py --config /etc/suricata-agent/config.yaml
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal

# Security
NoNewPrivileges=true
PrivateTmp=true

# Resource limits
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target'

#==============================================================================
# COLORS & FORMATTING
#==============================================================================

RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
BLUE='\033[0;34m'
NC='\033[0m' # No Color

log_info() {
    echo -e "${BLUE}[INFO]${NC} $1"
}

log_success() {
    echo -e "${GREEN}[SUCCESS]${NC} $1"
}

log_warn() {
    echo -e "${YELLOW}[WARN]${NC} $1"
}

log_error() {
    echo -e "${RED}[ERROR]${NC} $1"
}

#==============================================================================
# HELPER FUNCTIONS
#==============================================================================

check_root() {
    if [ "$EUID" -ne 0 ]; then
        log_error "Please run as root (use sudo)"
        exit 1
    fi
}

detect_os() {
    if [ -f /etc/os-release ]; then
        . /etc/os-release
        OS=$ID
        OS_VERSION=$VERSION_ID
    else
        log_error "Cannot detect OS. /etc/os-release not found."
        exit 1
    fi

    log_info "Detected OS: $OS $OS_VERSION"
}

check_dependencies() {
    log_info "Checking dependencies..."

    # Python 3.8+
    if ! command -v python3 &> /dev/null; then
        log_error "Python 3 not found. Installing..."
        install_python
    else
        PYTHON_VERSION=$(python3 --version | awk '{print $2}')
        log_success "Python $PYTHON_VERSION found"
    fi

    # pip
    if ! command -v pip3 &> /dev/null; then
        log_info "Installing pip..."
        if [ "$OS" = "ubuntu" ] || [ "$OS" = "debian" ]; then
            apt-get update -qq
            apt-get install -y python3-pip
        elif [ "$OS" = "centos" ] || [ "$OS" = "rhel" ]; then
            yum install -y python3-pip
        fi
    fi

    # systemd
    if ! command -v systemctl &> /dev/null; then
        log_error "systemd not found. This installer requires systemd."
        exit 1
    fi

    # Suricata
    if ! command -v suricata &> /dev/null; then
        log_warn "Suricata not found in PATH. Make sure it's installed."
    else
        SURICATA_VERSION=$(suricata --version | head -n1)
        log_success "Found: $SURICATA_VERSION"
    fi
}

install_python() {
    if [ "$OS" = "ubuntu" ] || [ "$OS" = "debian" ]; then
        apt-get update -qq
        apt-get install -y python3 python3-pip
    elif [ "$OS" = "centos" ] || [ "$OS" = "rhel" ]; then
        yum install -y python3 python3-pip
    else
        log_error "Unsupported OS for auto-install: $OS"
        exit 1
    fi
}

check_connectivity() {
    log_info "Testing connection to dashboard: $DASHBOARD_URL"

    if ! curl -sSf -o /dev/null "$DASHBOARD_URL/api/v1/health" --connect-timeout 10; then
        log_error "Cannot connect to dashboard at $DASHBOARD_URL"
        log_error "Please check network connectivity and dashboard URL"
        exit 1
    fi

    log_success "Dashboard is reachable"
}

parse_arguments() {
    while [[ $# -gt 0 ]]; do
        case $1 in
            --name)
                AGENT_NAME="$2"
                shift 2
                ;;
            --tags)
                AGENT_TAGS="$2"
                shift 2
                ;;
            --help)
                show_help
                exit 0
                ;;
            *)
                log_error "Unknown option: $1"
                show_help
                exit 1
                ;;
        esac
    done
}

show_help() {
    cat << EOF
Suricata Dashboard Agent Installer

Usage:
    curl -sSL $DASHBOARD_URL/agent/install.sh | sudo bash
    curl -sSL $DASHBOARD_URL/agent/install.sh | sudo bash -s -- [options]

Options:
    --name NAME     Agent name (default: hostname)
    --tags TAGS     Comma-separated tags (e.g., "production,dmz")
    --help          Show this help message

Examples:
    # Basic install (interactive)
    curl -sSL $DASHBOARD_URL/agent/install.sh | sudo bash

    # Non-interactive with custom name
    curl -sSL $DASHBOARD_URL/agent/install.sh | sudo bash -s -- --name web-server-01

    # With tags
    curl -sSL $DASHBOARD_URL/agent/install.sh | sudo bash -s -- --name web-01 --tags production,critical

EOF
}

#==============================================================================
# INSTALLATION STEPS
#==============================================================================

step_1_preflight() {
    log_info "===== Step 1/8: Preflight Checks ====="

    check_root
    detect_os
    check_dependencies
    check_connectivity

    log_success "Preflight checks passed"
}

step_2_install_deps() {
    log_info "===== Step 2/8: Installing Python Dependencies ====="

    pip3 install --quiet --upgrade pip

    # Install agent dependencies
    pip3 install --quiet \
        requests>=2.31.0 \
        watchdog>=3.0.0 \
        websocket-client>=1.6.0 \
        cryptography>=41.0.0 \
        PyYAML>=6.0.0

    log_success "Dependencies installed"
}

step_3_deploy_files() {
    log_info "===== Step 3/8: Deploying Agent Files ====="

    # Create directories
    mkdir -p "$INSTALL_DIR"
    mkdir -p "$CONFIG_DIR"
    mkdir -p "$DATA_DIR"
    mkdir -p "$LOG_DIR"

    # Decode and extract agent package
    log_info "Extracting agent package..."
    echo "$AGENT_PACKAGE_B64" | base64 -d | tar -xz -C "$INSTALL_DIR"

    # Set permissions
    chmod +x "$INSTALL_DIR/agent.py"
    chmod 755 "$INSTALL_DIR"
    chmod 700 "$CONFIG_DIR"  # Sensitive (contains token)
    chmod 755 "$DATA_DIR"
    chmod 755 "$LOG_DIR"

    log_success "Agent files deployed to $INSTALL_DIR"
}

step_4_generate_config() {
    log_info "===== Step 4/8: Generating Configuration ====="

    # Auto-detect Suricata paths
    SURICATA_EVE_LOG="/var/log/suricata/eve.json"
    SURICATA_CONFIG="/etc/suricata/suricata.yaml"
    SURICATA_LOG_DIR="/var/log/suricata"

    # Verify paths exist
    if [ ! -f "$SURICATA_EVE_LOG" ]; then
        log_warn "eve.json not found at $SURICATA_EVE_LOG"
        read -p "Enter path to eve.json: " SURICATA_EVE_LOG
    fi

    if [ ! -f "$SURICATA_CONFIG" ]; then
        log_warn "suricata.yaml not found at $SURICATA_CONFIG"
        read -p "Enter path to suricata.yaml: " SURICATA_CONFIG
    fi

    # Prompt for agent name if not provided
    if [ -z "$AGENT_NAME" ]; then
        DEFAULT_NAME=$(hostname)
        read -p "Enter agent name [default: $DEFAULT_NAME]: " AGENT_NAME
        AGENT_NAME=${AGENT_NAME:-$DEFAULT_NAME}
    fi

    # Generate config.yaml
    cat > "$CONFIG_DIR/config.yaml" << EOF
# Suricata Dashboard Agent Configuration
# Generated: $(date -Iseconds)

agent:
  name: "$AGENT_NAME"
  token: "$AGENT_TOKEN"
  tags: [$(echo "$AGENT_TAGS" | sed 's/,/", "/g' | sed 's/^/"/' | sed 's/$/"/' || echo '')]

dashboard:
  url: "$DASHBOARD_URL"
  api_version: "v1"
  verify_ssl: true

  # Connection settings
  connection:
    transport: "websocket"  # websocket or http
    websocket_url: "${DASHBOARD_URL/https/wss}/ws/v1/agent"
    fallback_to_http: true
    reconnect_interval: 5
    max_reconnect_delay: 300

  # Heartbeat
  heartbeat_interval: 30

suricata:
  # Log files to monitor
  eve_log: "$SURICATA_EVE_LOG"
  suricata_log: "$SURICATA_LOG_DIR/suricata.log"
  fast_log: "$SURICATA_LOG_DIR/fast.log"

  # Config file
  config_file: "$SURICATA_CONFIG"

  # Control
  pid_file: "/var/run/suricata.pid"
  control_socket: "/var/run/suricata/suricata-command.socket"

# Event streaming
streaming:
  batch_size: 100
  batch_timeout: 5
  compression: true

# Local buffer (SQLite)
buffer:
  database: "$DATA_DIR/buffer.db"
  max_events: 100000
  max_size_mb: 500

# Logging
logging:
  level: "INFO"
  file: "$LOG_DIR/agent.log"
  max_size_mb: 100
  backup_count: 5
EOF

    chmod 600 "$CONFIG_DIR/config.yaml"  # Secure (contains token)

    log_success "Configuration generated: $CONFIG_DIR/config.yaml"
}

step_5_install_service() {
    log_info "===== Step 5/8: Installing systemd Service ====="

    echo "$SYSTEMD_SERVICE" > /etc/systemd/system/suricata-agent.service

    systemctl daemon-reload

    log_success "Systemd service installed"
}

step_6_register() {
    log_info "===== Step 6/8: Registering with Dashboard ====="

    # Collect system info
    HOSTNAME=$(hostname)
    IP_ADDRESS=$(hostname -I | awk '{print $1}')
    OS_INFO="$OS $OS_VERSION"
    KERNEL=$(uname -r)
    SURICATA_VERSION=$(suricata --version 2>/dev/null | head -n1 | awk '{print $3}' || echo "unknown")

    # Register via API
    RESPONSE=$(curl -sSf -X POST "$DASHBOARD_URL/api/v1/agents/register" \
        -H "X-Agent-Token: $AGENT_TOKEN" \
        -H "Content-Type: application/json" \
        -d "{
            \"name\": \"$AGENT_NAME\",
            \"hostname\": \"$HOSTNAME\",
            \"ip_address\": \"$IP_ADDRESS\",
            \"tags\": [$(echo "$AGENT_TAGS" | sed 's/,/", "/g' | sed 's/^/"/' | sed 's/$/"/' || echo '')],
            \"suricata_version\": \"$SURICATA_VERSION\",
            \"agent_version\": \"1.0.0\",
            \"system_info\": {
                \"os\": \"$OS_INFO\",
                \"kernel\": \"$KERNEL\",
                \"arch\": \"$(uname -m)\"
            }
        }" 2>&1)

    if [ $? -eq 0 ]; then
        AGENT_ID=$(echo "$RESPONSE" | grep -o '"agent_id":[0-9]*' | cut -d':' -f2)
        log_success "Agent registered successfully (ID: $AGENT_ID)"

        # Save agent ID to config
        echo "  id: $AGENT_ID" >> "$CONFIG_DIR/config.yaml"
    else
        log_error "Registration failed: $RESPONSE"
        exit 1
    fi
}

step_7_start_agent() {
    log_info "===== Step 7/8: Starting Agent ====="

    systemctl enable suricata-agent
    systemctl start suricata-agent

    log_success "Agent service started"
}

step_8_verify() {
    log_info "===== Step 8/8: Verification ====="

    sleep 5

    # Check if service is running
    if systemctl is-active --quiet suricata-agent; then
        log_success "Agent is running"
    else
        log_error "Agent failed to start. Check logs:"
        log_error "  journalctl -u suricata-agent -n 50"
        exit 1
    fi

    # Check connection
    log_info "Verifying dashboard connection..."
    sleep 5

    if journalctl -u suricata-agent -n 50 | grep -q "Connected to dashboard"; then
        log_success "Agent connected to dashboard"
    else
        log_warn "Agent may not be connected yet. Check logs if issues persist."
    fi

    # Display summary
    echo ""
    echo "╔════════════════════════════════════════════════════════════╗"
    echo "║        Suricata Dashboard Agent Installation Complete      ║"
    echo "╚════════════════════════════════════════════════════════════╝"
    echo ""
    echo "  Agent Name:     $AGENT_NAME"
    echo "  Agent ID:       $AGENT_ID"
    echo "  Dashboard:      $DASHBOARD_URL"
    echo "  Status:         $(systemctl is-active suricata-agent)"
    echo ""
    echo "Useful Commands:"
    echo "  systemctl status suricata-agent    # Check status"
    echo "  journalctl -u suricata-agent -f    # View logs"
    echo "  systemctl restart suricata-agent   # Restart agent"
    echo ""
    echo "View your agent in the dashboard:"
    echo "  $DASHBOARD_URL/agents/$AGENT_ID"
    echo ""
}

#==============================================================================
# MAIN
#==============================================================================

main() {
    echo ""
    echo "╔════════════════════════════════════════════════════════════╗"
    echo "║         Suricata Dashboard Agent Installer                 ║"
    echo "║         Dashboard: $DASHBOARD_URL"
    echo "╚════════════════════════════════════════════════════════════╝"
    echo ""

    parse_arguments "$@"

    step_1_preflight
    step_2_install_deps
    step_3_deploy_files
    step_4_generate_config
    step_5_install_service
    step_6_register
    step_7_start_agent
    step_8_verify

    log_success "Installation complete!"
}

# Run main function
main "$@"
```

## Generator: `agent/installer/generator.py`

```python
"""
Generate custom installer script with embedded agent code and token.
"""

import base64
import tarfile
import io
import os
from typing import Dict
from datetime import datetime

class InstallerGenerator:
    def __init__(self, dashboard_url: str, template_path: str):
        self.dashboard_url = dashboard_url
        self.template_path = template_path

    def generate(self, agent_token: str, agent_name: str = "", tags: str = "") -> str:
        """
        Generate installer script with embedded agent and configuration.

        Args:
            agent_token: Pre-generated encrypted token
            agent_name: Optional pre-configured name
            tags: Comma-separated tags

        Returns:
            Complete installer script as string
        """

        # Read template
        with open(self.template_path, 'r') as f:
            template = f.read()

        # Package agent code
        agent_package_b64 = self._package_agent()

        # Replace template variables
        script = template.replace('{{DASHBOARD_URL}}', self.dashboard_url)
        script = script.replace('{{AGENT_TOKEN}}', agent_token)
        script = script.replace('{{AGENT_NAME}}', agent_name)
        script = script.replace('{{AGENT_TAGS}}', tags)
        script = script.replace('{{AGENT_PACKAGE_B64}}', agent_package_b64)
        script = script.replace('{{GENERATED_AT}}', datetime.utcnow().isoformat())

        return script

    def _package_agent(self) -> str:
        """
        Package entire agent directory into tar.gz, base64 encode.

        Returns:
            Base64 encoded tar.gz of agent code
        """

        agent_dir = os.path.join(os.path.dirname(__file__), '..')

        # Create tar.gz in memory
        tar_buffer = io.BytesIO()
        with tarfile.open(fileobj=tar_buffer, mode='w:gz') as tar:
            tar.add(agent_dir, arcname='.')

        # Base64 encode
        tar_buffer.seek(0)
        encoded = base64.b64encode(tar_buffer.read()).decode('utf-8')

        return encoded
```

## API Endpoint: `apps/api/installer.py`

```python
"""
API endpoint to generate and serve installer script.
"""

from flask import Blueprint, request, Response
from agent.installer.generator import InstallerGenerator
from apps.lib.auth import generate_agent_token

blueprint = Blueprint('installer', __name__)

@blueprint.route('/agent/install.sh', methods=['GET'])
def get_installer():
    """
    Generate custom installer script.

    Query parameters:
        - token: Pre-generated token (optional, will generate if not provided)
        - name: Agent name (optional)
        - tags: Comma-separated tags (optional)

    Returns:
        Bash script for download
    """

    # Get or generate token
    token = request.args.get('token')
    if not token:
        token = generate_agent_token()

    name = request.args.get('name', '')
    tags = request.args.get('tags', '')

    # Generate installer
    generator = InstallerGenerator(
        dashboard_url=request.host_url.rstrip('/'),
        template_path='agent/installer/template.sh'
    )

    script = generator.generate(
        agent_token=token,
        agent_name=name,
        tags=tags
    )

    # Return as downloadable script
    return Response(
        script,
        mimetype='text/x-shellscript',
        headers={
            'Content-Disposition': 'attachment; filename=install-suricata-agent.sh',
            'X-Agent-Token': token  # Include token in header for reference
        }
    )
```

## Usage Examples

### 1. Basic Installation (Interactive)
```bash
curl -sSL https://dashboard.example.com/agent/install.sh | sudo bash
```

### 2. Non-Interactive with Custom Name
```bash
curl -sSL https://dashboard.example.com/agent/install.sh | \
    sudo bash -s -- --name web-server-01 --tags production,dmz
```

### 3. Download First, Install Later
```bash
# Download
curl -sSL https://dashboard.example.com/agent/install.sh -o install-agent.sh

# Review script
less install-agent.sh

# Install
sudo bash install-agent.sh --name my-agent
```

### 4. Pre-configured Install (from dashboard UI)
```bash
# User generates install command from web UI with pre-filled token
curl -sSL "https://dashboard.example.com/agent/install.sh?token=abc123&name=web-01" | sudo bash
```

## Security Considerations

1. **HTTPS Only**: Installer must be served over HTTPS
2. **Token in Script**: Token is embedded (acceptable since it's encrypted and one-time use)
3. **Script Verification**: Users can download and review before executing
4. **Checksum**: Optional SHA256 checksum for script integrity
5. **Signed Scripts**: Future: GPG signature verification

## Troubleshooting

### Installation Failed

```bash
# Check logs during install
tail -f /var/log/suricata-agent/agent.log

# Manual service check
systemctl status suricata-agent
journalctl -u suricata-agent -n 100
```

### Uninstall Agent

```bash
# Stop service
sudo systemctl stop suricata-agent
sudo systemctl disable suricata-agent

# Remove files
sudo rm -rf /opt/suricata-agent
sudo rm -rf /etc/suricata-agent
sudo rm -rf /var/lib/suricata-agent
sudo rm -rf /var/log/suricata-agent
sudo rm /etc/systemd/system/suricata-agent.service

# Reload systemd
sudo systemctl daemon-reload
```
